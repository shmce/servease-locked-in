# ServEase

ServEase is a mobile-first service marketplace built around an Expo React Native app and a NestJS HTTP microservices backend.

## Project Baseline

- [AGENTS.md](AGENTS.md): repository rules and agent operating constraints.
- [DESIGN.md](DESIGN.md): product experience and UI design source of truth.
- [docs/](docs/README.md): workflow, architecture, API, data ownership, testing, and implementation plan.

## Planned Structure

- `backend/`: NestJS monorepo with an API Gateway and HTTP-only services.
- `mobile/`: Expo React Native app.

Implementation follows [docs/implementation-plan.md](docs/implementation-plan.md).
